# Ночь в Бухаресте

Готовое статическое приглашение для GitHub Pages. Сборка и сервер не нужны.

Сохранены пять исходных картинок, раскрывающийся ковёр, постраничные свайпы, музыка по кругу и кнопка звука. Музыка включается только после нажатия на ковёр.

## Публикация

1. Создать публичный репозиторий `buharest-night`.
2. Загрузить содержимое этого архива в корень репозитория: `index.html`, `styles.css`, `slideshow.js`, `.nojekyll`, `resources/` и этот файл.
3. Открыть Settings → Pages → Build and deployment → Deploy from a branch.
4. Выбрать ветку `main`, папку `/(root)` и нажать Save.
5. Дождаться сообщения Your site is live. Использовать адрес из этого сообщения.

Все пути относительные: сайт работает и в подпапке репозитория. Нет подключений к AppDeploy, внешних шрифтов, аналитики, серверных API или CDN. Все картинки и MP3 находятся в `resources/`.

## Проверка

Открыть сайт → нажать на ковёр → проверить музыку → свайп вверх на вторую страницу → выключить ноту → свайп и убедиться, что звук остался выключен → включить ноту. Последний слайд не перелистывается на пустой экран.
